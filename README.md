# BookOCR Web v5.3 Experimental — Manual Cleanup

針對 Detector 偶爾把污點、殘影、頁碼碎片抓成欄位。

例如畫面中的小欄：
9 / 20 / 22

我們不把自動過濾調太兇，因為真正的短標題（例如 3 字書名/章名）
也可能很短。

所以 v5.3 加入人工清理。

## 圖上刪除

每條藍色中心線編號旁會有紅色 `×`。

點 `×`：
- 藍線排除
- V3 strips 重新計算
- 對應 OCR 結果刪除
- 全文同步更新

## Column 下方刪除

每張 Column 卡片下面有：

`× 刪除此欄`

效果跟圖上刪除一樣。

## OCR 結果下方刪除

逐欄 OCR 結果也有：

`× 刪除此欄`

適合 OCR 完後才發現某個雜訊欄。

## 恢復全部刪除

按：

`恢復全部刪除`

會恢復藍線 / Column。
如果已經 OCR 過，恢復後重新按一次 Recognition 才會補回文字。

## 為什麼不全自動刪短欄

因為：
- 污點可能很短
- 章名 / 頁碼 / 書名也可能很短

手動刪除比激進 filter 安全。

v5.2 的：
- 書脊重疊
- 頁面安全留白
- 直欄上下延伸
仍全部保留。
