# BookOCR Web v5.4 Experimental — Interactive Column Editor

v5.4 在 v5.3 的「刪除誤抓欄」之外，再加入每欄手動微調。

## 怎麼用

在藍色中心線圖上：
- 點藍線
- 或點藍色編號

就會選取該欄。

選取後：
- 藍線變黃色
- 黃色半透明區域 = 真正 V3/OCR corridor
- 下方顯示此欄編輯器

## 每欄可調

### 欄寬倍率
0.45x ～ 1.80x

用途：
- 左右筆畫被削掉 → 放大
- 混到隔壁欄 → 縮小

### 水平偏移
-1.50 ～ +1.50 字

用途：
- 整個 corridor 偏左 / 偏右
- 中心線抓得不夠準

### 上方延伸
-1.0 ～ +3.0 字

### 下方延伸
-1.0 ～ +3.0 字

用途：
- 最上面 / 最下面少字
- 或反過來想縮短欄位

## 即時 OCR

如果 Recognition 已經載入過：
調 slider 後只會：
1. 重抽選取欄
2. 只重跑選取欄 OCR
3. 更新逐欄結果
4. 更新全文

不會重新跑整頁 UVDoc / Detector / OCR。

為避免 slider 一動就狂跑模型，使用約 320ms debounce。

## 還原 / 刪除

編輯器內：
- 還原此欄
- 刪除此欄

v5.3 的圖上紅色 ×、Column 刪除、OCR 結果刪除仍保留。
