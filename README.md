# BookOCR Web v5.1 Experimental — Spine Overlap Fix

v4.5 仍然是穩定直書備份。
v5.1 是 v5 Auto 實驗版的書脊裁切修正。

## 問題

舊版「忽略中央書脊」會真的刪掉中央一條影像。

如果正文靠近裝訂處，文字在送進 UVDoc 前就已經不見了。

## v5.1

改成：

`書脊重疊保留 3.0%`

也就是：

- 左頁多保留一點書脊右側
- 右頁多保留一點書脊左側
- 中央一小段同時存在於兩頁

寧可之後有少量重複，也不要永久切字。

建議值：
- 一般：2%～5%
- 很難攤平、文字貼裝訂：5%～7%
- 吃到太多另一頁：降到 1%～2%

橫排跨頁模式也使用相同的 overlap 邏輯。

GitHub workflow 不用改。
